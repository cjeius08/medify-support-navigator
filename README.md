# Medify Air Support Navigator

A standalone, professional knowledge base for Medify Air customer-support work.

## Included

- Guided support-process navigation
- Room-size air-purifier finder
- Active product specifications and lifecycle flags
- Email, chat, and voice support scripts
- Call-note generator
- Search, favorites, call mode, and dark mode
- Visible review states for unresolved source conflicts

The live website is deployed through GitHub Pages.
